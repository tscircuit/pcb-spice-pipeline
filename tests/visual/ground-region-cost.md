# DDR extraction ground-region cost

This native TSX reproduction uses the three-lane DQ/DQS/DQSn fixture in `tests/fixtures/native-ddr-timeout.tsx`. The [top closeup](ground-region-top-closeup.svg) shows the three signal routes between U1 and U3 and two ground reference vias below them; the [full top view](ground-region-top.svg) shows their position on the board. Compare the [local bottom plane](ground-region-local-bottom.svg) with the [board-sized bottom plane](ground-region-wide-bottom.svg). Both views use a 100 × 68 mm board; the pours measure 22 × 14 mm and 96 × 64 mm, respectively. The test verifies that all rendered records other than the pour and nondeterministic warnings are identical.

Run `node --import tsx --test tests/ground-region-cost.test.ts` to regenerate both refined FastHenry decks and print their ground-segment counts. At commit `ff7013c`, the 1.5 mm mesh and five-filament refinement generated 1,019 segments for the local plane and 8,720 for the board-sized plane. The test does not require the same counts; a future optimization should be free to improve them. Regenerate the layer views with `node --import tsx tests/visual/ground-region-cost.ts`.

The fixture uses two different physical pour outlines, a single unbroken ground plane, simple straight signal routes, and no vendor models. It does not change the extraction pipeline, crop an existing board, run FastHenry or predict solver time. Fewer segments do not establish equivalent impedance or eye results. A candidate crop must preserve actual return connectivity and cutouts, pass independent mesh refinement and converge as the modeled region is expanded.
